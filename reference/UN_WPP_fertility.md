# UN World Population Prospects 2024: Fertility Rates

Estimated Total Fertility Rate (live births per 1,000 women) by age
(15–49) and country, from the 2024 UN WPP.

## Usage

``` r
UN_WPP_fertility
```

## Format

A data frame with columns: - area: Country or territory - iso3: 3-digit
ISO code - year: Year - x15 to x49: Live births per 1,000 women, by age

## Source

UN DESA Population Division, World Population Prospects 2024
