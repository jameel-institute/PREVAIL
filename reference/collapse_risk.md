# Sum (or Average) an Array over its Risk Dimension

Sum (or Average) an Array over its Risk Dimension

## Usage

``` r
collapse_risk(x, f = sum)
```

## Arguments

- x:

  A matrix (age by stratum) or an array (age by stratum by risk group).

- f:

  Function applied over the risk dimension.

## Value

A matrix (age by stratum).
