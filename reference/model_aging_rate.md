# Daily Ageing Probability of Each Model Age Group

Daily Ageing Probability of Each Model Age Group

## Usage

``` r
model_aging_rate(aggregate_age, new_age_breaks)
```

## Arguments

- aggregate_age:

  Logical; whether single years of age are aggregated into
  \`new_age_breaks\`.

- new_age_breaks:

  Age break points of the aggregated groups.

## Value

Numeric vector (one value per age group when aggregated, otherwise a
single value).
