# UN World Population Prospects 2024: Net Migration Rate

Net migration rate per 1,000 population, with no age disaggregation,
from the 2024 UN WPP.

## Usage

``` r
UN_WPP_migration
```

## Format

A data frame with columns: - area: Country or territory - iso3: 3-digit
ISO code - year: Year - migration_rate_1000: Net migration rate

## Source

UN DESA Population Division, World Population Prospects 2024
