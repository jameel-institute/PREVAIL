# WHO Global Reported Cases of Vaccine-Preventable Diseases (1980–2023)

Annual country-level case reports for vaccine-preventable diseases
collected by WHO via the Joint Reporting Form.

## Usage

``` r
WHO_disease_reports
```

## Format

A data frame with columns: - iso3: 3-digit ISO country code - name:
Country or territory name - year: Year of report - disease_short: Short
disease name - disease_description: Full description of disease - cases:
Number of reported cases

## Source

WHO Immunization Dashboard: https://immunizationdata.who.int/
