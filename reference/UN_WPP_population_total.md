# UN World Population Prospects 2024: Total Population

Total population (in thousands) by single year of age (0–100), as of 1
July, from the 2024 UN WPP.

## Usage

``` r
UN_WPP_population_total
```

## Format

A data frame with columns: - area: Country or territory - iso3: 3-digit
ISO code - year: Year - x0 to x100: Total population counts

## Source

UN DESA Population Division, World Population Prospects 2024
