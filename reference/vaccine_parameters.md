# Vaccine Efficacy and Duration Parameters

Dose-specific efficacy and duration estimates for measles, diphtheria,
and pertussis.

## Usage

``` r
vaccine_parameters
```

## Format

A data frame with columns: - vaccine: Vaccine name - disease: Disease
name - parameter: Parameter name - value: Value of parameter - unit:
Unit of measurement - dose: Dose number

## Source

Literature estimates from peer-reviewed sources
