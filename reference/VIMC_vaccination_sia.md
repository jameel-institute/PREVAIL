# Supplementary Immunization Activities (SIA) Coverage Estimates

Coverage estimates for SIAs from WHO and supplementary sources, as used
in Shattock et al. (2024).

## Usage

``` r
VIMC_vaccination_sia
```

## Format

A data frame with columns: - area: Country - year: Year - age: Age -
coverage: Coverage - disease: Disease - vaccine: Vaccine

## Source

Shattock et al., 2024, The Lancet.
https://doi.org/10.1016/S0140-6736(24)00850-X
